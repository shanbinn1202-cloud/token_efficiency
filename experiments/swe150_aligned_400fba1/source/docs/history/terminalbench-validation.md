**`observation_query`: GPU-validated.** Job 3399437 (`TB16_PASS_VERIFIED`), the dry run of `observation_query` with the 8,192-token budget at runtime commit `68d19b4`, with the settings of job 3399075 (above): all 16 trials ended, the server completed 384 requests (18 of them rebuilds), the selection was active on 238 of them, every request was token-exact against its native receipt, nothing was preempted, the server never stalled for capacity, every check passed, and the evidence was verified again after the fetch. The pool never ran short, so no idle Pages were released.

A first dry run of `full`, job 3398129 at runtime `0d37346` and without `--release-idle-pages`, ended when the engine failed: the idle sessions' Pages filled the attention pool, a turn admitted while nothing ran found no free block, and vLLM preempted it. Commit `68d19b4` makes such a turn wait, and every server now runs with `--release-idle-pages` (A.3). That run is not part of the validation.

**`goal_query`: the dry run passed at `53e3b7a` (status of 2026-10-24; 65,536 tokens, 32 GiB).** The first dry run of `goal_query`, job 3429670 at runtime `120bc3c` (the 16 tasks of the dry subset at `-n 16`), failed: about 9 minutes in, the server stopped answering, and 8 of the 16 trials ran into their 900-s agent timeout. The cause was in the Goal features: every Goal construction normalizes the session's previous reply with the quoted-literal pattern of the upstream `dram_kv/goals/features.py` (`normalize_action`), which backtracks exponentially on an unclosed quote followed by backslash escapes. The reply before the stalled turn was the run's only reply cut at `max_tokens` (4,096 tokens, inside a JSON string). CPython's regex engine holds the GIL for the whole match, so the engine process froze, and the 90-s heartbeat between the API server and the engine revoked the server. Runtime `53e3b7a` replaces the pattern at server start with a linear-time pass that returns the same output; the upstream files and their pins are unchanged ([docs/history.md](../history.md#history)). The rerun at `53e3b7a`, job 3434533, the first GPU run of the fix, with the flags of A.3 at the earlier sizes (65,536 tokens, `--kv-cache-gib 32`, `--dram-arena-gib 64`): `TB16_PASS_VERIFIED`. The server did not stall, although `make-doom-for-mips` again produced a reply cut at 4,096 tokens; 8 of the 16 trials were solved and 6 ran into their 900-s agent timeout; output throughput 177.6 tokens/s over the runner's span. The join with the ATIF trajectories passed for all 16 trials (`JOIN_PASS`, rejoined offline, 177.63 tokens/s) once it accounted the two replies cut at `max_tokens` that Terminus 2 does not record as ATIF steps: one in the main loop and one full-summary call of its context-limit fallback, 8,192 tokens in all (A.10).

**The optimized switches.** The dry runs of `full` and `observation_query` at `68d19b4` (jobs 3399075, 3399437) ran with `--decode-fastpath` alone. `--decode-fastpath2`, `--decode-fastpath3` and `--deferred-completion-io` (A.3) first passed a Qwen Terminal-Bench run in job 3434533 (`goal_query`, above); they had run in job 3429670, which stalled (above), on Gemma in job 3433706 (`TB16_PASS_VERIFIED` after re-verification, below), and in the SWE-bench jobs 3428631 and 3429500 (runtime `120bc3c`). The decode check on Qwen (job 3429022, runtime `120bc3c`; verified offline as `SPD3_PARTIAL_PASS_VERIFIED`: every runtime server passed, partial only because some rounds lack the stock servers' measurement windows) found no differences beyond the run-to-run spread: at 16 concurrent sessions no configuration is byte-identical from run to run (A.13), and among requests with byte-identical prompts the replies were identical in 76–83 % for `--decode-fastpath3` against `--decode-fastpath2` and in 76–80 % for `--deferred-completion-io` on against off, against 81–82 % for the same configuration with only the step profiler toggled; the differences concentrate in rounds of 8 or more concurrent sessions, and in rounds of 1 to 4 sessions the compared same-prompt replies were identical except one in each of two pairs, both in a round of 2 sessions (`--decode-fastpath3` against `--decode-fastpath2` without the profiler; `--deferred-completion-io` with `observation_query`) ([docs/reference.md section 4.11](../reference.md#411-decode-fast-path-on-by-default)).
