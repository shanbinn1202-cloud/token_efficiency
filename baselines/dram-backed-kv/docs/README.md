# Documentation map

- `current/`: documents that describe the active Online Selector V2 implementation.
- `research/`: motivation and design rationale that remain useful but are not runbooks.
- `archive/framework-v1/`: the former long README for the recorded-replay framework.
- `archive/selector-v1/`: frozen offline text-embedding, hybrid, retention, and rejected semantic-span work.

Every archived document carries a status banner. Code and current experiment parameters take precedence over historical proposals.
